# ♻️ C2C (중고거래 커뮤니티 플랫폼)

지역 기반 중고거래와 커뮤니티 기능을 제공하는 웹 플랫폼입니다.

사용자는 중고거래를 통해 자원 재사용에 참여하고, 커뮤니티를 통해 친환경 생활 노하우를 공유할 수 있습니다. 또한 활동 통계와 탄소 기여도 기능을 제공하여 사용자가 자신의 친환경 활동을 직관적으로 확인할 수 있도록 구현하였습니다.

# 🚀 주요 구현 내용

## 1. 게시글 통계 차트 구현

사용자가 최근 2주 동안 작성한 커뮤니티 게시글과 중고거래 게시글 수를 시각적으로 확인할 수 있도록 통계 차트를 구현하였습니다.

### 구현 내용

* Oracle SQL을 활용하여 최근 14일 데이터 집계
* 게시글이 없는 날짜도 출력되도록 날짜 테이블 생성
* `UNION ALL`을 활용하여 커뮤니티/중고거래 게시글 데이터 통합
* `LEFT JOIN`을 활용하여 누락 날짜 처리
* `NVL`을 활용하여 NULL 값을 0으로 변환
* Recharts를 활용한 데이터 시각화

### 구현 포인트

* 프론트엔드는 단순 출력만 담당
* 데이터 가공 및 집계를 백엔드에서 처리
* 날짜 기준으로 정렬된 데이터를 제공하여 차트의 일관성 확보

## 4. 게시글 조회수 처리

게시글 상세 페이지 진입 시 조회수를 증가시키는 기능을 구현하였습니다.

### 문제

상세 페이지에서 조회수를 증가시키는 경우 새로고침이나 직접 URL 접근 시 조회수가 중복 증가하거나 누락될 수 있었습니다.

### 해결

게시글 목록에서 제목 클릭 시 비동기 요청으로 조회수를 먼저 증가시킨 후 상세 페이지로 이동하도록 구현하였습니다.

### 결과

* 조회수 반영 누락 방지
* 중복 증가 문제 완화
* 데이터 일관성 향상

# 🔧 트러블 슈팅

## 이미지 처리 로직 중복

### 문제

프로필 이미지 수정과 회원 정보 수정 과정에서 이미지 등록 및 삭제 로직이 중복되어 있었습니다.

### 개선 방향

파일 업로드 및 삭제 기능을 공통 서비스로 분리하여 중복 코드를 제거하고 유지보수성을 높일 수 있도록 개선할 계획입니다.

---

## HTML 태그 포함 검색 문제

### 문제

게시글 내용 저장 시 HTML 태그가 함께 저장되어 검색 결과에 영향을 주었습니다.

### 해결

정규식을 활용하여 HTML 태그를 제거한 후 검색하도록 구현하였습니다.

### 개선 방향

추후에는 검색 전용 텍스트 컬럼을 별도로 저장하여 보다 안정적인 검색 기능을 구현할 예정입니다.

# 📚 프로젝트 회고

프로젝트를 진행하며 요구사항이 지속적으로 변경되는 상황을 경험하면서 실제 개발은 초기 설계대로만 진행되지 않는다는 점을 체감하였습니다. 기능 추가와 수정이 반복되는 과정에서 문제 해결 능력과 유연하게 대응하는 태도의 중요성을 배울 수 있었습니다.

특히 커뮤니티 게시글 조회수 기능을 구현하면서 단순 기능 구현을 넘어 데이터 일관성과 사용자 경험을 함께 고려하는 개발의 중요성을 느낄 수 있었습니다. 조회수 증가 시점에 대해 고민하고 비동기 처리 방식을 적용하며 서비스 관점에서 문제를 바라보는 경험을 얻을 수 있었습니다.

또한 프로필 이미지 등록·수정·삭제 기능을 구현하면서 파일 업로드와 파일 관리 전반에 대한 이해를 넓힐 수 있었습니다. 서버 파일과 데이터베이스 데이터를 함께 관리해야 하는 실제 서비스 환경을 경험하며 다양한 예외 상황을 고려하는 습관을 기를 수 있었습니다.

팀 프로젝트 과정에서는 팀원들의 코드를 분석하고 수정하면서 다양한 구현 방식을 접할 수 있었으며, 협업 시 코드 가독성과 유지보수성의 중요성을 체감할 수 있었습니다.

이번 프로젝트를 통해 React 기반 프론트엔드 개발 역량뿐만 아니라 협업, 문제 해결, 유지보수 관점까지 함께 경험할 수 있었으며 개발자로서 한 단계 성장할 수 있는 계기가 되었습니다.
